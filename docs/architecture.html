🔗 C4: SCM 因果通信

专家被视为智能体，通过可学习通信矩阵 Wcomm 进行消息传递，精调专家权重。

S_j' = S_j + gate · Receive(Σᵢ W[i,j] · Message(Sᵢ))

DAG 约束: h(W) = tr(exp(W⊙W)) − N = 0
通信矩阵约束：
✓ Softmax 归一化（沿发送维度）
✓ 对角线置零（无自环）
✓ NOTEARS DAG 约束（无环）
✓ 稀疏正则化 L₁
✓ 值域截断 [-2, 2]

联合损失函数 (C7)
Ltotal = Ltask + α · Lconsist + β · Lsparse + γ(t) · Lcausal + δ · Lbalance + ε · Lortho
Ltask — MSE / MAE 预测损失
Lconsist — 输入输出结构一致性
Lsparse — 通信矩阵 L₁ 稀疏
Lcausal — DAG 约束 h(W)²（带预热）
Lbalance — 专家负载均衡
Lortho — 原型正交正则化
三阶段渐进训练 (C8)

Stage 1: 自监督预训练

仅训练编码器和权重估计器

  • 对比学习：相似段落 → 相似 z
  • 掩码重建：预测被遮蔽的 token
  • 结构预测：从 z 预测统计量

Stage 2: 端到端微调

全模型联合训练，Ltotal 损失

  • 分模块学习率（原型 0.1×, Wcomm 3×）
  • DAG 约束线性预热
  • 余弦退火学习率调度
  • 梯度裁剪 (max_norm=1.0)

Stage 3: 强化微调 (RFT)

冻结骨干，PPO 训练路由策略

  • 冻结编码器和专家网络
  • PPO 训练路由器 + 工具适配器
  • 奖励 = 预测精度 + 验证一致性
  • Clip ε=0.2, GAE λ=0.95
